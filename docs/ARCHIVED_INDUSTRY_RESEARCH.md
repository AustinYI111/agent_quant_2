# 历史行业分类：研究重建与实际观察分开

`archived_industry_research` 为历史原公告提供独立的研究时点规则。日常真实观察仍使用原 `industry_features` 模块；本模块不改写首次抓取时间，不声称有当年保存的历史快照。调用者必须先核验原公告、附件、提取文件的哈希与分类内容；本模块负责输入身份、完整行数、时间边界及计算，不能代替原件审核。

规则：只接受明确绑定原历史公告的分类整表，公开日期后下一交易日才可用；每次切换整份最新可见公告，不为新表中消失的股票继承旧分类。每项行业指标至少十个有效成员，未知值保留。只能在研究区间计算，独立区间不能进入候选选参。

已用五份实际中上协原件核对九个边界日期。2024-02-08 的公告，真实交易日历上的首次可用日是 2024-02-19；2025-09-30 的公告首次可用日是 2025-10-09。抓取时间仍为 2026 年。[核对证据](reports/evidence/ARCHIVED_INDUSTRY_GATE_20261023.json)。

尚未将这些分类用于训练。新增行业特征缓存、行业及完整组合的固定滚动拟合仍待完成；网站迁移后的文件也未认证与当年发布字节完全相同。历史研究重建不能冒充真实历史观察，更不能用当前行业分类回填过去。

## 已完成的历史输入检查点

现已拼接 21 份历史整表，86,441 条 A 股分类身份记录。旧表修正 16 条门类错位、补回两条遗漏；较新五份表用第二套 PDF 表格解析逐行交叉核对，结果一致。原始文件保留，换代码只使用已核实的同发行人映射，B 股和北交所记录显式排除。

```powershell
python -m ashare_mvp.archived_industry_inputs --project . --out artifacts/phase2/archived_industry_memberships_20261023_v1
```

以上为当前不可覆盖检查点，复跑应改新输出名，并先恢复所有原件、提取表与审核记录。它核对源哈希、身份、完整行数、公开日期及真实观察时刻，对原模型 388 个信号日逐一核验。1,509,411 个原始合格样本中，1,489,907 个能够对应当时已公布的分类，约98.7%；未因此删样本。三项因子的有效成员数量仍需在特征缓存阶段检查。

**最旧版本距信号公开时间达817天。** 未找到2022年新公告的区间只能沿用最后一份已公布整表，缺少的新股票分类仍为未知，不能回填现在的分类。这是已披露的陈旧信息风险。历史原始字节版本仍未认证；不能把档案研究重建当作当年实际抓取记录或实时分类源。
