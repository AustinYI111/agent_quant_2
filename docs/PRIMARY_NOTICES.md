# 原公告候选采集

用项目内入口获取指定发行人、除权日期附近的实施公告和更正公告。原文件、查询响应与实际观察时钟写入指定工作盘的新目录；采集结果仍需逐页复核，不自动加入事件表或账户。

```powershell
python -m ashare_mvp.primary_notice_capture `
  --work-root $env:PQR_WORK_ROOT `
  --code 000951 --ex-date 2021-09-29 `
  --out '@work/research/notice_000951_new' `
  --max-pages 2 --max-notices 4 --max-pdf-bytes 2000000
```

请在项目目录执行，或传`--project`。`PQR_WORK_ROOT`应指向已有的外部工作目录，不能与代码目录重叠。每次使用新的输出目录；已有原件和失败收据不会被覆盖。上例是历史资料采集，不表示当年已取得该公告。

默认以“实施”为关键词，在除权日前后45个自然日内检索。筛选涵盖“权益分派暨资本公积金转增股本实施公告”“利润分配实施公告”“关于权益分派实施的公告”等实际写法，也保留更正公告。候选可能涉及不同权益安排，仍须人工确认证券类别、实际金额、日期及更正关系。

每页记录数、来源声明的总条数、`hasMore`及跨页证券与公告身份必须一致。重复公告、总数变化、缺页、跨证券结果、非官方附件、跨站重定向、非PDF内容、文件篡改或超过资源上限都会失败并保存收据。空查询结果只代表本次检索未找到候选，不能作为无公司行动的证明。

默认最多20页、20份PDF、每份20MiB；可按实际需要降低上限。触及上限时停止并标记失败，不将部分结果记为完整。原件仍使用既有`original_candidate_notice_capture_v1`收据，可接入后续复核契约；`reviewed`和`candidates_applied`始终为false。
