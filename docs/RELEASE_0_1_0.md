# MVP 0.1.0 交付说明

本版提供可运行的多因子研究程序：可扩展基本面、估值和动量因子，欧奈尔风格可选指标，LightGBM月度排序、Top20输出、数据时点校验、按标签成熟日期隔离的滚动训练、3/6/12个月分组绩效、交易成本模拟，以及手动CSV持仓、技术观察区间、结构化财报指标和预测实现记录。

## 可复现的完整运行

安装说明见README。以下命令不访问网络，使用明确标识的合成价格和合成持仓，与用户实际账户无关：

```powershell
python -m ashare_mvp.release_check --out artifacts/release_check
```

程序分别运行基准和可选因子模型，检查月度20只证券、训练标签严格早于截止日期、三个持有期限均有成熟样本、模型文件保存、最新排序、日报估值以及重复写入预测台账的幂等性。检查失败退出非零；输出release_check.json、输入/输出哈希、模型、排序、绩效CSV和中文日报。输出目录必须为空，不覆盖历史结果。GitHub Actions也执行这项检查。

可选因子`growth_acceleration`更名为`earnings_revenue_growth_spread`，数值仍为利润增速减营收增速。该数值表示增速差，不能解释为跨期增长加速度。旧模型/结果保留原名称；新运行使用正确名称，应重新训练，勿混合比较不同配置的历史产物。

## 本版真实数据边界

公开源采集与断点恢复程序已实现，财务季度批次、市场分红方案和发行人支付历史已取得。证券生命周期5460/5470目标有结果；市场分红方案15549条取得一致的支付证据。行情仍在采集和补缺。这些结果不代表完整历史市场覆盖，当前源不能认证原始财报/公告版本。

真实全市场训练与绩效验证尚未完成，不能把合成运行收益作为真实投资收益。退市终值、差异化分红、原始财报版本及历史身份仍须解决。持仓CSV由用户稍后填写；原始年报正文/行业叙事抽取尚未实现。当前版本供研究与工程验证使用，不自动交易。
