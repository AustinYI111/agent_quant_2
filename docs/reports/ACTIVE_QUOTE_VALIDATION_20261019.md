# 有效代码与非交易日成交量校验（2026-10-19）

修复公开市场准备入口的校验顺序：先复用已有、按公告生效日期核验的同发行人代码规则，再对有效报价做价格／成交量校验。旧入口把生效前新别名的占位量也当作有效成交量，真实第一日sz.001872即因此停止。

## 最终行为

所有原始文件仍逐一验证哈希、日期、唯一键、字段、复权口径和历史状态。只有已核验代码政策明确不处于生效区间的别名行才隔离，原文件不修改、规则计数留审计；普通股票或真正有效报价不会因此删除。

实际交易状态为1时，成交量缺失继续阻塞。状态为0且成交量空缺时保留NaN，另存 `nontrading_unknown_volume.csv` 和SHA256，不填0、不推断交易。现有可买／可卖标志由状态禁止执行，选股仍要求当日volume>0。可选成交量因子继续面对原始未知值，不伪造观察。

无论是否交易，open／close／preclose缺失和任何负数仍阻塞；按具体日期、稳定发行人键、原交易代码和字段写入 `blocking_issues.csv`，不再只抛出无法定位的缺值错误。不填停牌价格，不用终止上市后的最后价伪造结算。
