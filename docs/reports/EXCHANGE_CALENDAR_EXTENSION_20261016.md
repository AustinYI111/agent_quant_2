# 延伸交易日历与财务可见时点（2026-10-16）

新增 `ashare_mvp.calendar_union.seal_calendar_union`，按市场采集 manifest 中的 SHA256 校验并封存两段日历。要求每段覆盖请求范围内所有日历日、顺序唯一且交易标志合法；重叠日期标志必须一致，中间缺日直接拒绝。保存原 manifest／日历副本及哈希，不修改原始来源。

调用示例（项目根目录）：

```python
from ashare_mvp.calendar_union import seal_calendar_union
seal_calendar_union([
    "artifacts/market_history_2018_2024",
    "artifacts/market_history_extension_2024_2025",
], "artifacts/exchange_calendar_union")
```

输出 `calendar.csv` 为既有 `normalize-financials --calendar` 可接受的格式。原行情任务可仍处于 running，来源状态会完整保存；该工具仅封存已经取得的日历，绝不声称所有对应价格已经观察到。未来日历不能让未来标签成熟，也不能替代行情和事件覆盖校验。
