## 连接规则

`combine-financials --code-changes config/same_issuer_code_changes.json` 在连接业绩与资产负债表之前统一经证据确认的稳定发行人键，再按同一报告期和各字段可见日期向后连接。后披露负债率不会提前填入；旧报告更新不替代更新报告期。没有对应记录仍保持 NaN。

输出保留 `earnings_provider_symbol`、`balance_provider_symbol` 及其复数形式的 JSON 来源清单。多个经验证别名若归到同一证券／报告期／可见日，必须在统一身份后除来源列之外的全部输入字段逐字段完全相等，才可显式合并；合并行的单一来源代码为空，所有代码保存在复数清单。相同代码的重复、金额或披露时点等任一字段冲突仍拒绝，不按近似相等或优先顺序任意取值。

每个实际合并组写入 `identity_alias_coalescing.csv`，记录依赖类型、发行人、报告期、可见日、全部原代码和消除的重复行数。原始输入文件不改，原面板和来源摘要哈希保留。身份策略及合并审计有独立哈希；数据准备要求财务、分红和特征使用同一份身份策略。
