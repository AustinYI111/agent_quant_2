## 可用入口与约束

`ashare_mvp.financial_union.union_financial_panels` 只接受同一封存交易日历派生的规范化面板。校验源面板／日历／来源摘要哈希、记录数、列合约、数值有限性和可见时钟。输出目录必须为空。

同一证券／报告期／可见日的多行，仅当所有数值、来源时钟和载荷相等才合并，并写入重复来源审计。任何冲突直接拒绝，不按来源优先或保留最后一行。晚修订使用其自身可见日；未来不可见记录、未识别交易所记录原样留存，后续依赖计算不把它们当作可见训练行。

```python
from ashare_mvp.financial_union import union_financial_panels
union_financial_panels([
    "artifacts/financial_normalized_2017_2023_extended_calendar1",
    "artifacts/financial_normalized_extension_2024_2025_1",
], "artifacts/exchange_calendar_2018_2025_union1",
   "artifacts/financial_earnings_union")
```

输出 `financial_panel.csv`、逐行 `record_origins.csv`、`equal_version_coalescing.csv`、日历副本及来源摘要／哈希。逐行来源保留输入索引和原行号；完全相等的额外来源在单独重复审计中追踪。两个财务源不修改。
