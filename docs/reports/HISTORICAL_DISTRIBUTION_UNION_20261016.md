## 合并与防重复

`merge-dividend-events` 接收原始计划对账结果与一个或多个规范化历史分红目录。要求输入文件哈希、行数、交易日历、来源执行年份模式及身份映射策略一致，封存每份输入和逐事件来源审计。它保留原有未解决的计划，不借补充来源抹除已有冲突。

同一发行人／除权日只计一次现金和股份；重复记录的权益和支付日期冲突即拒绝。相同权益的重复来源只增加审计，使用较晚的可见日期。新增事件保存原始供应商代码、文件名、行号、源动作哈希。未认证的历史版本仍是未认证状态，不因文件合并获得完整历史认证。

真实联调曾发现补充来源字段名与下游已映射标记冲突，导致价格审计拒绝；已改为专用来源字段并加入跨模块回归。旧失败输出保留供审计，最终使用 `dividend_history_union3`。

```powershell
python -m ashare_mvp.cli merge-dividend-events --base artifacts/dividend_payment_reconciliation_identity2 --supplements artifacts/retired_dividend_normalized_600068 --calendar artifacts/market_history_2018_2024/calendar.csv --code-changes config/same_issuer_code_changes.json --out artifacts/dividend_history_union3
```
