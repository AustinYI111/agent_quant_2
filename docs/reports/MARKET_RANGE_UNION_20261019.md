# 跨年份原始行情快照（2026-10-19）

新增 `merge-market-ranges`，复用封存日历合并相邻年份的原始日行情。已用真实2018—2024和2024—2025两段数据实际运行；扩展行情仍在续采，因此当前结果明确为 partial，不能作为完整训练集。

## 入口与约束

```powershell
python -m ashare_mvp.cli merge-market-ranges --data artifacts/market_history_2018_2024 artifacts/market_history_extension_2024_2025 --out artifacts/market_history_union
```

输出必须为空且与来源目录互不嵌套。先封存每个来源当时的 manifest、日历及来源哈希，再只按已封存版本选择日行情文件。原任务可继续采集，新快照不混入稍后新增的文件。

逐文件验证字节哈希、记录数、交易日期、证券唯一键、原始 adjustflag=3、历史 isST／tradestatus 和必需字段。重叠交易日必须字节完全一致，并保留所有来源索引；冲突拒绝，不选择较新来源。原始ST和北交所记录不在此阶段删除，选股候选池仍统一过滤。

不补造缺失交易日，不填充停牌／终值价格。输出保存 `missing_sessions.csv`、日行情、`calendar.csv`、输入 manifest 副本、`file_origins`、来源状态和缺失摘要；只有全部验证完成才写出可用 `manifest.json`。失败／中断输出不具有最终行情 manifest。结果设置 `read_only_snapshot=True`，既有采集器拒绝对其 resume；必须继续采集原目录，完成后另建快照。
