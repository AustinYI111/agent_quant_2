# 普通送转股份：新增锁定账户组件

已新增独立账户版本，处理“除权日已获得新增权益，但新股尚未上市”的情形。旧引擎、旧报告和固定行情缓存保持原样；**尚未完成新版本的独立核账及全历史重跑，因此不能把旧历史结果标为已修复。**

处理规则：登记日收盘记录原持股；除权日把新增数量记入独立锁定权益并计入资产价值；公告规定的上市日才转为可卖股份。锁定价值同时扣减买入目标，避免重复买入。缺少上市日期、未知持仓价格、股份缩减或不支持的重叠行动时停止并保留已有股份及权益，不按零处理。

三星新材原公告明确2022年5月19日除权、20日新增股上市，已绑定原PDF和捕获收据的哈希、实际观察及复核时钟、参数页码。公告未明确的实体到账日期保持未知，不用除权或上市日替代。公告是本次补取的历史研究证据，不认证2022年当时的数据字节版本。[来源契约](../../config/reviewed_ordinary_listings_20261104_v1.json)、[实际加载核对](evidence/ORDINARY_LISTING_ADMISSION_20261104.json)。

148项相关测试通过。实际SQLite反例中，新增账户在除权日仅卖原有股份，到次日上市才卖新增股份；现金、应收现金与股份总价值守恒。不含普通送转时，原账户及配股“参与／不参与”两种情景的净值、订单和配股台账逐字节一致。测试还覆盖来源篡改、错误日期、漏行动、缺价格、未知上市日期及整批失败前不修改权益。[代码哈希与检查范围](evidence/ORDINARY_SETTLEMENT_COMPONENT_20261104.json)。

开发接口为`OrdinaryListingBook`、`OrdinaryShareWallet`及`simulate_settled_account`。目前只有一项真实上市来源契约；完整来源覆盖、新账户独立审计、命令入口与从原起点重跑仍待完成。不得把组件测试通过当作完整历史执行验证，更不能当作盈利证明。
