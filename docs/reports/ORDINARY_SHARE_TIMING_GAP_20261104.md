# 普通转增股份可交易时点：已复现的缺口

现有`disk_account`及`rights_disk_account`都在除权日直接把普通持仓乘以股份倍数，并允许新增部分在当日卖出，未分离新增股份上市前的锁定权益。独立核账也沿用这一普通增股假设，因此此前通过的是该口径下的现金／股份算术重建，不是普通转增股交易时点认证。这个缺口尚未修复，旧结果保留，不能据此宣布完整可执行基准完成。

[三星新材原实施公告](https://static.cninfo.com.cn/finalpage/2022-05-12/1213323962.PDF)四页已实际渲染、逐页核对：2022-05-19除权，新增无限售转增股2022-05-20上市。原动作表的股份到账日期缺失，不能把未知的物理到账日期或除权日自行当成可卖日。

已使用真实SQLite账户流程运行一个小型合成反例：原股价13元，除权后10元、转增比例0.3，新增股份下一交易日才可卖。在除权日清仓时，两种旧引擎均卖出归一化金额1；原有可卖股份仅值0.76923077，其中0.23076923来自未上市的转增股份。它是程序反例，不是真实股票收益或策略绩效估计。[反例结果及执行代码哈希](evidence/ORDINARY_SHARE_TIMING_GAP_20261104.json)。

下一步需要补齐来源绑定的普通股份上市时点，并在新账户口径中把已获得但未上市的股份计入估值、排除可卖量；上市后再转为可交易股份。未知时点或未支持的重叠公司行动应停止并保留持仓权益。随后用独立实现核对现金、锁定股份、解锁及订单，重新运行研究对照。旧引擎和旧结果留作比较，不改写历史报告中的原数字。

本次没有升级模型、改动原预测、放宽价格校验，也没有声称问题已经解决。原始行情库未重新复制。数据库与原PDF继续只在本地外部工作目录，备份恢复暂缓，PR保持Draft，不合并main。
