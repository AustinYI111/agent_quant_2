# 第二阶段：遗漏现金分派与最新行情（2026-10-21）

本轮补充的是季度计划表未包含、但独立付款历史中存在的现金事件。它们不能因某个来源遗漏就被丢弃，也不能直接合并为未经核实的收入。

## 结果

- 补齐 2026-10-20 收盘行情：5,224 条原始记录，其中 5,223 条沪深 A 股。原始报价仍不等于可交易选股池。
- 8 条特别／临时分派已逐项核对官方公告和独立付款记录。付款事件从 4,327 个增至 4,335 个；原先独立接受集合中的未匹配现金降至 0。**不表示原始拒绝清单或所有市场事件已经解决。**
- 流式诊断覆盖 5,244 个历史发行人、2026 年截至 10 月 20 日的 988,159 条 A 股报价。此前 337 个参考价差异精确消除 8 个，并在新增交易日发现 1 个，剩余 330 个待核实；没有通过放宽价格容差消除差异。
- 原先 337 个差异的官方查询中，323 个找到实施公告；修正不同公告标题形式后补取 13 个，仍有 1 个未找到原文。这些原文多数尚未完成参考价条款复核，不能当成已通过。
- 新模块 24 项相关测试通过，覆盖文件哈希、付款及原始行锚点、重复计入、股份重整误入、公告时点和未匹配记录保留。全量 GitHub CI 见本提交 Checks。

执行哈希与计数见[轻量证据](evidence/PHASE2_CASH_SUPPLEMENTS_20261021.json)。本轮没有训练、选参或升级模型，没有发布最新 Top 20，也没有完成模拟账户或增量收益检验。

## 复现

先准备[前序付款复核](PHASE2_PAYMENT_REVIEW_20261020.md)的输出、八份官方 PDF、审查配置和日历，然后在项目根目录执行。输出目录必须不存在：

```powershell
.\.venv\Scripts\python.exe scripts/supplement_reviewed_cash.py `
  --data artifacts/phase2/normalized/payments_reviewed_v2_20261020 `
  --calendar artifacts/phase2/raw/market_capture_20261021/exchange_calendar.csv `
  --review config/reviewed_cash_supplements_20261021.json `
  --notices artifacts/phase2/official_extra_payments_20261020 `
  --out artifacts/phase2/normalized/payments_supplemented_new_run
```

补充事件要求与原未匹配记录的代码、除息日、现金、付款日、来源文件及原始行一致，并绑定公告 URL、哈希与页码。它只能新增明确的现金事件，不能替换现有股东权益，也不允许将重整转增当成普通送股；缺失的季度计划标签保持未知。

公开 Git 保存代码、配置、测试和轻量证据；公告原文、完整报价和付款结果仍在本地忽略目录，**尚未纳入第二阶段私有云备份**。保留旧快照，不覆盖第一阶段模型或数据。实际现金与参考现金分开记录，仍未模拟投资者特定税率及账户分币舍位；数据和模型均未获得实盘认证。
