# 真实三周期样本外回测与交付（2026-10-20）

真实5／20交易日及12自然月的9个年度滚动LightGBM候选模型和全部三周期净成本账户回测已完成。统一比较2023-02-01—2025-12-31，共711个交易日。5日结果显著落后基准，20日与12个月历史收益较高，但三个策略最大回撤均超过33%。没有据样本外结果改参或选择性替换基线。

## 数据、因子及训练边界

2018—2025原始行情1,942个交易日已封存并验证全部文件哈希，8,612,897原始行。准备后的真实研究库含8,609,196条报价、5,401个稳定发行人、148,348条财务事件，存续期漏报价0。信号日历史ST／*ST与北交所股票排除；原始记录与无法立即卖出的实际持仓仍保留。

`config/research_protocols/real_20261019.json`在查看样本外净值前冻结：验证起点2021-07-30，测试边界2023-01-31至2025-12-31，Top20、种子42、30／60树候选、60个月训练窗和至少12个月重训间隔。该协议记录冻结当时状态，不改写成实时进度。

实际因子样本1,509,411条；405个尝试日期中388个有样本，17个空日期均早于最早财务可见日2019-04-30。标签共1,892,522条，分别5日1,258,864、20日315,339、12个月318,319；已知结果分别1,246,406、308,661、247,427。未知目标不填零，不据未来结果删除预测候选。基础因子库支持基本面、估值、动量及可选欧奈尔指标；当前实证只使用冻结配置和公开可得字段，不伪造绝对市值或利润。

逐折训练最大标签终点早于隔离截止，验证选择仅使用测试前成熟标签，特征可见时点不晚于信号日。5日／12个月选30树，20日选60树，各保存3折。见[实际输入审计](evidence/real_horizon_input_audit_20261019.json)。这是算法时序检查，供应商原始财报历史版本仍未经独立认证。

整个输入仍有1,607处原始参考价差异及退市后期间门禁，默认严格准备检查没有被关闭或宣称全库认证。研究库采用`causal_segment_feature_index`，7,008个因果技术段，遇参考价缺口只重置技术历史；该指数从不用作持仓财富。未知训练收益造成的可得性偏差仍存在。
