# 除权参考比例与事件覆盖检查（2026-10-16）

## 修复的问题

公司回购专户不参与分配时，投资者实际取得的送转股份比例，可以不同于交易所按全部股本计算的虚拟除权比例。旧逻辑把实际 `share_multiplier` 同时用于价格验证，使已匹配的事件仍出现参考价差异。

新增可选 `reference_share_multiplier`，只用于参考价公式与报价精度检查；现金、持股数、新买入者收益和账户权益继续使用实际 `cash_per_share`／`share_multiplier`。未提供参考倍数时沿用实际倍数。倍数包含原有的一股，例如实际每股转增 0.4 股对应倍数 1.4。

审阅参考证据若提供该字段，必须同时提供 `expected_share_multiplier`，准确匹配原有实际股份权益。未审阅、时点不合规、非正／非有限、成对字段不完整、与现有参考值冲突均拒绝。原 12 条纯现金参考记录可继续使用；新增 3 条后累计为 15 条参考参数记录，实施事件审阅数仍为 31。

配置读取使用精确 JSON 小数解析，避免 1.39 等字面量解析产生漂移并在半分位改变四舍五入方向；模型、回测和数据准备的来源证据仍按原有机制封存。
