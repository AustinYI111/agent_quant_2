# 第六项配股核验与基准进度

财通证券601108已纳入基准。三周期、双配股政策共六份账户均实际运行并独立核账，延伸至2022-04-13；4月14日遇到000065参考价停点。完整等权基准仍未完成。

## 这次解决了什么

发行人上市公告中的总股本包含除权后其他持有人转债转股形成的170股。新增严格的发行人股本衔接规则：数量、种类、同类股份范围、起止日期及原公告页码都须完整，且转股发生在除权后、公告前。它只用于核平发行人总股本，不增加本模拟账户股份，不改变配股认购比例，也不改变账户现金。

原报价8.48元／除权参考8.09元，与交易所月度原始数据直接核对一致。根据实际发行数量计算得到8.10元的差异保留为诊断，没有倒改认购比例来迎合行情。原五项配股条款及价格核验完全保留。

原公告、交易所响应均实际于2026-11-04取得，属于事后研究证据，未认证历史原始版本。配置引用外部工作目录，不把原PDF或行情库提交Git。[条款与价格核验](evidence/SIXTH_RIGHTS_CASE_VERIFIED_20261104.json)。
