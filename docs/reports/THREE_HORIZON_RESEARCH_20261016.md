# 三周期 LightGBM 研究入口（2026-10-16）

已实现行情、时点财务／估值因子到 5d、20d、12m 独立 LightGBM 排序模型，再到净成本账户和指数比较的完整入口。合成数据端到端验证完成，真实全市场实验尚未完成；没有正式真实市场模型或盈利结论。

## 训练与时间隔离

复用十项基本面、估值、动量和波动因子，欧奈尔指标可选。候选池统一使用历史当日 ST／*ST 状态并排除北交所。保留历史行情及无法卖出的持仓，未成熟或缺失的未来收益不用于筛掉预测候选。

训练／验证／测试边界必须是已观察的交易日。每个周期按实际 label_end 清除跨边界标签，默认隔离一个交易日。只在历史验证集比较候选树数的日期平均 Spearman Rank IC；测试集不选参数。按默认十二个月滚动重新训练，使用此前六十个月且已成熟的标签，记录最大特征日期、最大标签终点和 cutoff。已成熟的较早测试期标签可以用于后续折次，尚未成熟标签不能使用。

每折保存 LightGBM 原生模型、周期单位、因子顺序、预处理说明、参数、依赖版本、训练时点、输入帧和代码 SHA256。恢复入口校验周期、特征顺序、模型哈希和 LightGBM 版本，不重新训练；输入仍须按相同因子合约计算。原始供应商版本并未因保存哈希而得到认证。

## 账户与比较

5d／20d 按交易间隔再平衡，缺少应有信号直接报错；12m 不早于入场满十二个日历月换仓。复用原始价格／公司行动权益账户，包含佣金、滑点及按日期变化的卖出印花税。不会把重叠标签平均收益当成净值。

三个账户按相同开盘估值日期范围对齐，首个信号较晚的周期在等待期间保持现金。已支付成本只扣一次；单边换手为成交买卖金额之和除以成本前权益再除二，另列排除首次实际买入日的换手。被阻塞订单不伪装成交、不计入成交换手；期末不强制清仓。

输出净收益／年化收益、绝对回撤、指数收益、相对财富收益和回撤、信息比率、交易成本、换手、受阻订单、Rank IC 及成熟标签覆盖。指数缺失日期禁止前向填充。沪深300现有来源为价格指数，未包含股息；策略与指数的股息差额不能直接解释为选股能力。

## 使用

先准备通过现有封存校验的公开数据目录（价格、财务、日历及原始公司行动）和带 benchmark_raw_v1 元数据、SHA256 的独立指数目录。以下日期仅为合成联调使用的窗口，真实实验须在数据通过校验后冻结。

```powershell
python -m ashare_mvp.cli run-three-horizons --data artifacts/sealed_dataset --benchmark artifacts/sealed_index --out artifacts/three_horizon_run --validation-start 2021-01-29 --test-start 2023-01-31 --test-end 2025-12-31 --asof 2025-12-31 --trees 30 60 --exploratory
```

输出目录必须为空。默认 Top20、年更训练、六十个月训练窗口；`--oneil` 启用可选因子，成本可显式配置。`--exploratory` 明确供应商原始版本未认证，不关闭输入哈希、标签时点或账户校验。

- `factor_samples.csv`、`labels.csv`：时点因子和独立周期标签。
- `models/rankings.csv`：预测分数、排名及候选选择，不含未来收益。
- `models/test_outcomes.csv`：单独保存后验评价数据。
- `models/training_audit.csv`、`validation_trials.csv`、`models.csv`：折次、调参和相对模型路径。
- `models/<周期>/<折次日期>/model.txt`、`metadata.json`：可恢复模型。
- `portfolios/<周期>/scheduled_top20.csv`、`daily_nav.csv`、`orders.csv`、`index_comparison.csv`、`summary.json`：组合、成交、指标。
- 根 `summary.json`：全部完成后才写入，保留来源、合成标记和未认证状态。

## 已实际运行的工程证据

本地 `artifacts/three_horizon_synthetic_e2e1` 使用二十五只模拟股票、2,100 个模拟工作日、52,500 行价格和合成基准，不是交易所真实日历。它完整执行公开格式转换、封存、因子计算、标签生成、三模型训练及净成本回测；测试窗口为 2023—2025 年，2021 年起验证，树数候选为 8／12。

共保存九个年度折次模型，预测信号日期数分别为 5d 153、20d 38、12m 36；满足持有期的实际再平衡为 152、38、3 次。三个账户统一比较 2023-02-01—2025-12-31，首笔信号前分别等待 1、6、0 个现金交易日。九个模型全部直接加载，逐折首日合计 225 条预测与原结果在绝对误差 1e-12 内一致，无需重训。

不把合成收益数字作为投资能力结论。本次完整 365 项测试通过（189.01 秒）；新测试覆盖标签终点隔离、未来特征拒绝、周期单位、成熟后滚动训练、缺失未来目标仍预测、恢复一致性、成交成本与换手手工算例、共同窗口、基准缺日拒绝和月度信号冒充短周期拒绝。

旧范围完整价格审计仍有 753 处未解释调整，另有终值／退市结算和三个 IPO 身份证据缺口，不能用删除历史失败证券的方式绕开。2024—2025 行情扩展仍在采集；八个财务季度原始采集已完成，仍需统一交易日历、区间合并、规范化与新事件覆盖。
